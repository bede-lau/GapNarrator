# GapNarrator Design Context

register: design

## Direction
GapNarrator should feel like a focused Apple-style production utility: quiet, precise, and native-app adjacent. The interface should make timing evidence feel trustworthy rather than decorative.

## Visual System
- Background: warm near-white app canvas with subtle neutral panels.
- Surfaces: white or translucent white, 1px neutral borders, 8px radius.
- Typography: system/Geist sans, compact labels, clear numeric hierarchy.
- Color: blue for active controls, red for timing failure, green for pass state, amber for reveal markers.
- Motion: minimal and functional. Use it to show playhead movement and state changes only.

## Layout Rules
- Top toolbar establishes product, upload action, and key safety note.
- Video and score inspector sit side-by-side on desktop.
- Timeline is the central proof object and should read like a pro media editor.
- Avoid nested decorative cards, glowing borders, dark dashboard styling, and generic AI-chat patterns.

## Copy Rules
- Say "timed audio-description track."
- Do not say "image analyzer" or "scene description bot."
- Mention that OpenAI analysis and TTS run server-side.
